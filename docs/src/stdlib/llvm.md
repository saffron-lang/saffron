# LLVM

```saffron
import "@llvm" as LLVM
```

A typed LLVM IR generation library for Saffron. It provides a builder-pattern API for constructing LLVM IR modules in memory and serializing them to text -- similar to Inkwell for Rust or llvmlite for Python, but written entirely in Saffron.

This library powers Saffron's self-hosted native compiler. You can also use it directly to build custom code generators, JIT compilation pipelines, or domain-specific compilers.

## Quick Start

```saffron
import "@llvm" as LLVM

// Create a module
var module: LLVM.Module = LLVM.Module("example")
module.set_target_triple("arm64-apple-macosx15.0.0")
module.set_data_layout("e-m:o-i64:64-i128:128-n32:64-S128")

// Define a function: i64 @add(i64 %a, i64 %b)
var params: List<LLVM.Param> = []
params.push(LLVM.Param("%a", LLVM.Type.I64))
params.push(LLVM.Param("%b", LLVM.Type.I64))

var fb: LLVM.FunctionBuilder = module.add_function("add", LLVM.Type.I64, params)
var entry: LLVM.BlockBuilder = LLVM.BlockBuilder(fb, fb.entry_block())

var result: LLVM.Value = entry.add(fb.param_value(0), fb.param_value(1))
entry.ret(result)

// Emit the IR text
IO.println(module.emit_ir())
```

Output:

```llvm
; Generated by Saffron @llvm library
target triple = "arm64-apple-macosx15.0.0"
target datalayout = "e-m:o-i64:64-i128:128-n32:64-S128"

define i64 @add(i64 %a, i64 %b) {
entry:
  %t1 = add i64 %a, %b
  ret i64 %t1
}
```

## Core Types

### `Type` enum

Represents LLVM IR types.

| Variant | Description |
|---------|-------------|
| `Type.Void` | Void type |
| `Type.I1` | 1-bit integer (boolean) |
| `Type.I8` | 8-bit integer |
| `Type.I32` | 32-bit integer |
| `Type.I64` | 64-bit integer |
| `Type.Ptr` | Opaque pointer |
| `Type.Float64` | 64-bit floating point (`double`) |
| `Type.Token` | Token type (for coroutine intrinsics) |
| `Type.Array(element, count)` | Fixed-size array |
| `Type.Struct(name, fields)` | Struct type (named or literal) |
| `Type.FnType(ret, params, variadic)` | Function type |
| `Type.NamedType(name)` | Reference to a named type |

Convenience constructors:

```saffron
var t: LLVM.Type = LLVM.ptr_type()
var t: LLVM.Type = LLVM.i64_type()
var t: LLVM.Type = LLVM.void_type()
var t: LLVM.Type = LLVM.float64_type()
var t: LLVM.Type = LLVM.fn_type(LLVM.Type.I64, [LLVM.Type.I64, LLVM.Type.I64])
var t: LLVM.Type = LLVM.fn_type_variadic(LLVM.Type.I64, [LLVM.Type.Ptr])
var t: LLVM.Type = LLVM.array_type(LLVM.Type.I8, 32)
var t: LLVM.Type = LLVM.struct_type("Point", [LLVM.Type.I64, LLVM.Type.I64])
var t: LLVM.Type = LLVM.named_type("Point")
```

### `Value` enum

Represents SSA values in LLVM IR.

| Variant | Description |
|---------|-------------|
| `Value.Instruction(name, ty)` | Result of an instruction (e.g., `%t1`) |
| `Value.Argument(name, ty, index)` | Function parameter |
| `Value.Constant(val)` | A compile-time constant |
| `Value.Global(name, ty)` | A global variable reference |
| `Value.Undef(ty)` | An undefined value |

You generally do not construct `Value` directly -- they are returned by builder methods and `param_value()`.

### `Const` enum

Compile-time constant values.

| Variant | Description |
|---------|-------------|
| `Const.Int(value, bits)` | Integer constant with bit width |
| `Const.Float(value)` | Float constant (as string) |
| `Const.Null(ty)` | Null pointer |
| `Const.StringLit(value, index)` | String constant reference |
| `Const.StructLit(fields)` | Struct literal initializer |
| `Const.ArrayLit(elements)` | Array literal initializer |
| `Const.ZeroInit(ty)` | Zero-initialized value |

Convenience constructors:

```saffron
var c: LLVM.Const = LLVM.int_const(42)       // i64 42
var c: LLVM.Const = LLVM.i32_const(10)       // i32 10
var c: LLVM.Const = LLVM.i8_const(255)       // i8 255
var c: LLVM.Const = LLVM.i1_const(1)         // i1 1
var c: LLVM.Const = LLVM.null_ptr()           // null
var c: LLVM.Const = LLVM.bool_const(true)     // i1 1
var c: LLVM.Const = LLVM.zero_init(LLVM.Type.I64)  // zeroinitializer
```

To use a constant as a `Value`:

```saffron
var forty_two: LLVM.Value = LLVM.Value.Constant(LLVM.int_const(42))
```

### `CmpPred` enum

Integer comparison predicates for `icmp`.

| Variant | Meaning |
|---------|---------|
| `CmpPred.Eq` | Equal |
| `CmpPred.Ne` | Not equal |
| `CmpPred.Slt` | Signed less than |
| `CmpPred.Sle` | Signed less or equal |
| `CmpPred.Sgt` | Signed greater than |
| `CmpPred.Sge` | Signed greater or equal |
| `CmpPred.Ult` | Unsigned less than |
| `CmpPred.Ule` | Unsigned less or equal |
| `CmpPred.Ugt` | Unsigned greater than |
| `CmpPred.Uge` | Unsigned greater or equal |

### `Linkage` enum

Linkage types for functions and globals.

| Variant | Description |
|---------|-------------|
| `Linkage.Default` | Default (no explicit linkage keyword) |
| `Linkage.LinkOnceODR` | Deduplicated across translation units |
| `Linkage.External` | Externally visible |
| `Linkage.Private` | Module-private |
| `Linkage.Weak` | Weak linkage |

## Module

The `Module` class is the top-level container for a compilation unit.

### Creating a module

```saffron
var module: LLVM.Module = LLVM.Module("my_program")
module.set_target_triple("arm64-apple-macosx15.0.0")
module.set_data_layout("e-m:o-i64:64-i128:128-n32:64-S128")
```

### Adding globals

```saffron
// Mutable global: @counter = global i64 0
module.add_global("@counter", LLVM.Type.I64, LLVM.int_const(0))

// Constant global: @magic = constant i64 42
module.add_constant("@magic", LLVM.Type.I64, LLVM.int_const(42))
```

The returned `GlobalDef` object has `linkage` and `is_constant` fields you can set:

```saffron
var g: LLVM.GlobalDef = module.add_global("@table", LLVM.Type.Ptr, LLVM.null_ptr())
g.linkage = LLVM.Linkage.Private
```

### String constants

```saffron
var idx: Float = module.add_string_constant("hello world")
var str_ref: LLVM.Value = module.string_ref(idx)
// str_ref refers to @.str.0 in the generated IR
```

### Named type definitions

```saffron
// %Object = type { ptr, i64, i64 }
module.add_type_def("Object", [LLVM.Type.Ptr, LLVM.Type.I64, LLVM.Type.I64])
```

### External declarations

```saffron
// declare i64 @puts(ptr)
module.add_declaration("puts", LLVM.Type.I64, [LLVM.Param("%s", LLVM.Type.Ptr)])

// declare i64 @printf(ptr, ...)
module.add_declaration_variadic("printf", LLVM.Type.I64, [LLVM.Param("%fmt", LLVM.Type.Ptr)])
```

### Emitting IR

```saffron
var ir: String = module.emit_ir()
IO.write_file("output.ll", ir)
```

## FunctionBuilder

Creates functions with basic blocks.

```saffron
var params: List<LLVM.Param> = []
params.push(LLVM.Param("%x", LLVM.Type.I64))
params.push(LLVM.Param("%y", LLVM.Type.I64))

var fb: LLVM.FunctionBuilder = module.add_function("multiply", LLVM.Type.I64, params)
```

### Builder methods

| Method | Description |
|--------|-------------|
| `fb.entry_block()` | Get the entry BasicBlock |
| `fb.new_block(name)` | Create a new named BasicBlock |
| `fb.param_value(index)` | Get parameter as a Value |
| `fb.fresh_local(ty)` | Generate a fresh SSA name |
| `fb.fresh_named(base, ty)` | Generate a named SSA name |
| `fb.add_attribute(attr)` | Add a function attribute (returns `fb` for chaining) |
| `fb.set_linkage(linkage)` | Set linkage (returns `fb` for chaining) |
| `fb.set_variadic()` | Mark as variadic (returns `fb` for chaining) |
| `fb.build()` | Finalize and return the FunctionDef |

### Example: function with multiple blocks

```saffron
var fb: LLVM.FunctionBuilder = module.add_function("abs", LLVM.Type.I64, [
    LLVM.Param("%n", LLVM.Type.I64)
])
fb.add_attribute("noinline")

var entry: LLVM.BlockBuilder = LLVM.BlockBuilder(fb, fb.entry_block())
var then_bb: LLVM.BasicBlock = fb.new_block("then")
var else_bb: LLVM.BasicBlock = fb.new_block("else")

var n: LLVM.Value = fb.param_value(0)
var zero: LLVM.Value = LLVM.Value.Constant(LLVM.int_const(0))
var is_neg: LLVM.Value = entry.icmp_slt(n, zero)
entry.cond_br(is_neg, then_bb, else_bb)

// then: return 0 - n
var then_builder: LLVM.BlockBuilder = LLVM.BlockBuilder(fb, then_bb)
var negated: LLVM.Value = then_builder.sub(zero, n)
then_builder.ret(negated)

// else: return n
var else_builder: LLVM.BlockBuilder = LLVM.BlockBuilder(fb, else_bb)
else_builder.ret(n)
```

## BlockBuilder

The primary instruction-emitting interface. Each method appends an instruction to the block and returns the result `Value`.

### Arithmetic

```saffron
var sum: LLVM.Value = bb.add(lhs, rhs)     // integer add
var diff: LLVM.Value = bb.sub(lhs, rhs)    // integer sub
var prod: LLVM.Value = bb.mul(lhs, rhs)    // integer mul
var quot: LLVM.Value = bb.sdiv(lhs, rhs)   // signed div
var rem: LLVM.Value = bb.srem(lhs, rhs)    // signed remainder
```

### Floating-point arithmetic

```saffron
var sum: LLVM.Value = bb.fadd(lhs, rhs)    // double add
var diff: LLVM.Value = bb.fsub(lhs, rhs)   // double sub
var prod: LLVM.Value = bb.fmul(lhs, rhs)   // double mul
var quot: LLVM.Value = bb.fdiv(lhs, rhs)   // double div
```

### Bitwise operations

```saffron
var a: LLVM.Value = bb.and_op(lhs, rhs)    // bitwise AND
var o: LLVM.Value = bb.or_op(lhs, rhs)     // bitwise OR
var x: LLVM.Value = bb.xor_op(lhs, rhs)    // bitwise XOR
var s: LLVM.Value = bb.shl(lhs, rhs)       // shift left
var r: LLVM.Value = bb.lshr(lhs, rhs)      // logical shift right
var a: LLVM.Value = bb.ashr(lhs, rhs)      // arithmetic shift right
```

### Comparisons

```saffron
// Generic integer comparison
var cmp: LLVM.Value = bb.icmp(LLVM.CmpPred.Eq, lhs, rhs)

// Convenience methods
var eq: LLVM.Value = bb.icmp_eq(lhs, rhs)
var ne: LLVM.Value = bb.icmp_ne(lhs, rhs)
var lt: LLVM.Value = bb.icmp_slt(lhs, rhs)
var le: LLVM.Value = bb.icmp_sle(lhs, rhs)
var gt: LLVM.Value = bb.icmp_sgt(lhs, rhs)
var ge: LLVM.Value = bb.icmp_sge(lhs, rhs)
var ult: LLVM.Value = bb.icmp_ult(lhs, rhs)
var uge: LLVM.Value = bb.icmp_uge(lhs, rhs)

// Floating-point comparison (predicate as string)
var flt: LLVM.Value = bb.fcmp("olt", lhs, rhs)
var feq: LLVM.Value = bb.fcmp("oeq", lhs, rhs)
```

### Memory

```saffron
// Stack allocation
var slot: LLVM.Value = bb.alloca(LLVM.Type.I64, "x")

// Store a value
bb.store(some_value, slot)

// Load from a pointer
var loaded: LLVM.Value = bb.load(LLVM.Type.I64, slot)

// GEP (general)
var indices: List<LLVM.Value> = [
    LLVM.Value.Constant(LLVM.i32_const(0)),
    LLVM.Value.Constant(LLVM.i32_const(2))
]
var field_ptr: LLVM.Value = bb.gep(struct_ty, ptr, indices)

// GEP for struct field access (convenience)
var field_ptr: LLVM.Value = bb.gep_struct(struct_ty, ptr, 2)
```

### Conversions

```saffron
var i: LLVM.Value = bb.ptrtoint(ptr_val, LLVM.Type.I64)
var p: LLVM.Value = bb.inttoptr(int_val, LLVM.Type.Ptr)
var b: LLVM.Value = bb.bitcast(val, LLVM.Type.Ptr)
var w: LLVM.Value = bb.zext(i8_val, LLVM.Type.I64)     // zero extend
var s: LLVM.Value = bb.sext(i8_val, LLVM.Type.I64)     // sign extend
var t: LLVM.Value = bb.trunc(i64_val, LLVM.Type.I8)    // truncate
var f: LLVM.Value = bb.sitofp(int_val, LLVM.Type.Float64)  // int -> double
var n: LLVM.Value = bb.fptosi(fp_val, LLVM.Type.I64)       // double -> int
```

### Calls

```saffron
// Call a named function with a return value
var result: LLVM.Value = bb.call("my_func", LLVM.Type.I64, [arg1, arg2])

// Call a void function
bb.call_void("printf", [fmt_str, value])

// Indirect call through a function pointer
var result: LLVM.Value = bb.call_indirect(fn_ptr, fn_type, [arg1])

// Void indirect call
bb.call_void_indirect(fn_ptr, fn_type, [arg1])

// Convenience: call returning ptr
var p: LLVM.Value = bb.call_ptr("malloc", [size])

// Convenience: call returning token
var tok: LLVM.Value = bb.call_token("llvm.coro.id", [args])
```

### Phi and Select

```saffron
// Phi node: merge values from different predecessors
var incoming: List<LLVM.PhiIncoming> = []
incoming.push(LLVM.PhiIncoming(val_from_a, "block_a"))
incoming.push(LLVM.PhiIncoming(val_from_b, "block_b"))
var merged: LLVM.Value = bb.phi(LLVM.Type.I64, incoming)

// Select: ternary in one instruction
var chosen: LLVM.Value = bb.select(cond, then_val, else_val)
```

### Memcpy

```saffron
bb.memcpy(dst_ptr, src_ptr, byte_count, false)
```

### Terminators

Every basic block must end with exactly one terminator.

```saffron
// Unconditional branch
bb.br(target_block)
bb.br_label("target_label")

// Conditional branch
bb.cond_br(cond, then_block, else_block)
bb.cond_br_labels(cond, "then_label", "else_label")

// Switch
var cases: List<LLVM.SwitchCase> = []
cases.push(LLVM.SwitchCase(LLVM.i32_const(0), "case_0"))
cases.push(LLVM.SwitchCase(LLVM.i32_const(1), "case_1"))
bb.switch_br_label(tag_val, "default_label", cases)

// Return
bb.ret(value)
bb.ret_void()

// Unreachable
bb.unreachable()
```

Terminators are idempotent -- calling a terminator on an already-terminated block is a no-op.

## NanBox

The `NanBox` class provides high-level helpers for Saffron's NaN-boxed runtime value representation, where all values are encoded as `i64`.

```saffron
var nanbox: LLVM.NanBox = LLVM.NanBox(bb, "arm64")
// For WebAssembly: LLVM.NanBox(bb, "wasm32")
```

### Tag/untag operations

```saffron
// Integer tagging
var boxed: LLVM.Value = nanbox.tag_int(raw_i64)
var raw: LLVM.Value = nanbox.untag_int(boxed_val)

// Pointer tagging
var boxed: LLVM.Value = nanbox.tag_ptr(ptr)
var ptr: LLVM.Value = nanbox.untag_ptr(boxed_val)

// Float tagging (double <-> NaN-boxed i64)
var boxed: LLVM.Value = nanbox.tag_float(double_val)
var f: LLVM.Value = nanbox.untag_float(boxed_val)

// Bool tagging
var boxed: LLVM.Value = nanbox.tag_bool(i1_val)
var b: LLVM.Value = nanbox.untag_bool(boxed_val)

// Nil constant
var nil_val: LLVM.Value = nanbox.nil()
```

### Platform-aware pointer conversion

On native (arm64/x86_64) pointers are 64-bit, but on wasm32 they are 32-bit. These methods handle the difference:

```saffron
// ptr -> i64 (zext on wasm32, direct ptrtoint on native)
var int_val: LLVM.Value = nanbox.ptr_to_val(ptr)

// i64 -> ptr (trunc on wasm32, direct inttoptr on native)
var ptr_val: LLVM.Value = nanbox.val_to_ptr(int_val)
```

### Enum operations

```saffron
// Simple enums: (tag << 56) | payload
var enum_val: LLVM.Value = nanbox.build_simple_enum(2, payload)
var enum_val: LLVM.Value = nanbox.build_simple_enum_no_payload(0)
var tag: LLVM.Value = nanbox.extract_simple_tag(enum_val)
var payload: LLVM.Value = nanbox.extract_simple_payload(enum_val)

// Heap-allocated enums (multi-field): tag is first i64 slot
var tag: LLVM.Value = nanbox.extract_heap_tag(boxed_ptr_as_i64)
var field: LLVM.Value = nanbox.extract_heap_field(boxed_ptr_as_i64, 0)
```

### Switching blocks

After a suspend point or branch, update the NanBox to emit into a new block:

```saffron
nanbox.set_block(new_block_builder)
```

## GCRoots

The `GCRoots` class manages a shadow-stack garbage collector. It emits calls to the runtime GC functions to track live heap references.

```saffron
var gc: LLVM.GCRoots = LLVM.GCRoots(bb, false)
// Set identity_mode to true to disable all GC calls (useful for simple functions)
```

### Methods

| Method | Description |
|--------|-------------|
| `gc.push_root(alloca_ptr)` | Register an alloca as a GC root |
| `gc.pop_all()` | Pop all roots for this function (call before every `ret`) |
| `gc.pop_n(n)` | Pop a specific number of roots |
| `gc.enable()` | Enable GC (called at program entry) |
| `gc.disable()` | Disable GC (for critical sections) |
| `gc.alloc(size)` | GC-tracked allocation (returns `ptr`) |
| `gc.alloc_zeroed(size)` | GC-tracked zeroed allocation (returns `ptr`) |
| `gc.zero_init(alloca_ptr)` | Zero an alloca to prevent GC scanning garbage |
| `gc.set_block(new_bb)` | Switch to emitting into a different block |
| `gc.get_root_count()` | Get the current number of registered roots |

### Example

```saffron
var gc: LLVM.GCRoots = LLVM.GCRoots(entry_builder, false)

// Register stack slots as GC roots
var obj_slot: LLVM.Value = entry_builder.alloca(LLVM.Type.I64, "obj")
gc.zero_init(obj_slot)
gc.push_root(obj_slot)

// ... emit function body ...

// Before returning, pop all roots
gc.pop_all()
entry_builder.ret(result)
```

## CoroBuilder

The `CoroBuilder` class encapsulates the LLVM coroutine intrinsic sequence, generating the full preamble (coro.id, coro.begin), suspend points, and epilogue (final suspend, cleanup, destroy).

### Creating a coroutine

```saffron
var fb: LLVM.FunctionBuilder = module.add_function("my_coro", LLVM.Type.Ptr, params)
fb.add_attribute("noinline")
fb.add_attribute("optnone")
fb.add_attribute("presplitcoroutine")

var coro: LLVM.CoroBuilder = LLVM.CoroBuilder(fb)
```

The constructor emits the coroutine preamble into the entry block:
- `llvm.coro.id` -- get coroutine ID token
- `llvm.coro.size.i64` -- get frame size
- `malloc` -- allocate frame
- `llvm.coro.begin` -- get coroutine handle

### Suspend points

```saffron
// Get a builder positioned after the preamble
var bb: LLVM.BlockBuilder = LLVM.BlockBuilder(fb, fb.entry_block())

// ... emit body instructions ...

// Suspend: terminates current block, returns a builder for the resume block
bb = coro.suspend(bb)

// ... continue emitting after resume ...
```

Each `suspend()` call generates:
- `llvm.coro.save` + `llvm.coro.suspend`
- A switch on the suspend result (0 = resume, 1 = cleanup)
- Returns a `BlockBuilder` positioned at the new resume block

### Finalizing

```saffron
coro.finalize(bb)
```

Emits the final suspend, cleanup (free coroutine memory), and suspend/return blocks.

### Coroutine handle

```saffron
var hdl: LLVM.Value = coro.handle()
// The handle is a ptr returned to the caller for resume/destroy
```

### Caller-side operations

```saffron
// Check if coroutine is done
var done: LLVM.Value = coro.emit_done_check(caller_bb, handle)

// Resume a suspended coroutine
coro.emit_resume(caller_bb, handle)

// Destroy a coroutine (cleanup)
coro.emit_destroy(caller_bb, handle)
```

### Required declarations

Coroutines need these intrinsics declared in the module. The `coro_intrinsic_decls()` function returns the metadata for them:

```saffron
// You'll typically declare these via module.add_declaration():
module.add_declaration("llvm.coro.id", LLVM.Type.Token, [
    LLVM.Param("%0", LLVM.Type.I32),
    LLVM.Param("%1", LLVM.Type.Ptr),
    LLVM.Param("%2", LLVM.Type.Ptr),
    LLVM.Param("%3", LLVM.Type.Ptr)
])
module.add_declaration("llvm.coro.size.i64", LLVM.Type.I64, [])
module.add_declaration("llvm.coro.begin", LLVM.Type.Ptr, [
    LLVM.Param("%0", LLVM.Type.Token),
    LLVM.Param("%1", LLVM.Type.Ptr)
])
// ... and so on for save, suspend, end, free, done, resume, destroy
```

## Complete Example: Factorial Function

A full example that generates a recursive factorial function:

```saffron
import "@llvm" as LLVM

var module: LLVM.Module = LLVM.Module("factorial")
module.set_target_triple("arm64-apple-macosx15.0.0")

// declare i64 @printf(ptr, ...)
module.add_declaration_variadic("printf", LLVM.Type.I64, [
    LLVM.Param("%fmt", LLVM.Type.Ptr)
])

// Format string
var fmt_idx: Float = module.add_string_constant("factorial(10) = %ld\n")

// define i64 @factorial(i64 %n)
var fb: LLVM.FunctionBuilder = module.add_function("factorial", LLVM.Type.I64, [
    LLVM.Param("%n", LLVM.Type.I64)
])

var entry: LLVM.BlockBuilder = LLVM.BlockBuilder(fb, fb.entry_block())
var then_bb: LLVM.BasicBlock = fb.new_block("base_case")
var else_bb: LLVM.BasicBlock = fb.new_block("recurse")

var n: LLVM.Value = fb.param_value(0)
var one: LLVM.Value = LLVM.Value.Constant(LLVM.int_const(1))
var is_base: LLVM.Value = entry.icmp_sle(n, one)
entry.cond_br(is_base, then_bb, else_bb)

// Base case: return 1
var then_builder: LLVM.BlockBuilder = LLVM.BlockBuilder(fb, then_bb)
then_builder.ret(one)

// Recursive case: return n * factorial(n - 1)
var else_builder: LLVM.BlockBuilder = LLVM.BlockBuilder(fb, else_bb)
var n_minus_1: LLVM.Value = else_builder.sub(n, one)
var sub_result: LLVM.Value = else_builder.call("factorial", LLVM.Type.I64, [n_minus_1])
var product: LLVM.Value = else_builder.mul(n, sub_result)
else_builder.ret(product)

// define i64 @main()
var main_fb: LLVM.FunctionBuilder = module.add_function("main", LLVM.Type.I64, [])
var main_entry: LLVM.BlockBuilder = LLVM.BlockBuilder(main_fb, main_fb.entry_block())

var ten: LLVM.Value = LLVM.Value.Constant(LLVM.int_const(10))
var fact_result: LLVM.Value = main_entry.call("factorial", LLVM.Type.I64, [ten])
var fmt_ref: LLVM.Value = module.string_ref(fmt_idx)
main_entry.call_void("printf", [fmt_ref, fact_result])
main_entry.ret(LLVM.Value.Constant(LLVM.int_const(0)))

IO.println(module.emit_ir())
```

## Source Files

The library is organized into these modules:

| File | Purpose |
|------|---------|
| `src/lib/llvm.sf` | Entry point, re-exports all submodules |
| `src/lib/llvm/types.sf` | Type, Value, Const, CmpPred, Linkage enums and formatting |
| `src/lib/llvm/instructions.sf` | Instruction and Terminator enums, IR text formatting |
| `src/lib/llvm/module.sf` | Module class (globals, type defs, string constants, emit_ir) |
| `src/lib/llvm/function.sf` | Param, BasicBlock, FunctionDef, FunctionBuilder |
| `src/lib/llvm/block.sf` | BlockBuilder (all instruction emission methods) |
| `src/lib/llvm/nanbox.sf` | NanBox helpers for runtime value encoding |
| `src/lib/llvm/gc.sf` | GCRoots shadow-stack management |
| `src/lib/llvm/coro.sf` | CoroBuilder for LLVM coroutine intrinsics |
